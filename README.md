## 🧭 关于我

这里记录我围绕实际需求构建的工具与应用：从记账和个人工作台，到脚本管理与故障调查。

- 📱 **跨平台应用**：让手机与电脑上的日常使用更连贯。
- ⚙️ **脚本与项目管理**：把脚本、版本和项目资料整理得更清楚。
- 🔎 **故障调查**：结合业务资料与运行证据，探索有依据的诊断流程。
- 🧰 **个人效率**：把分散的工作入口整理成自己的工作台。
